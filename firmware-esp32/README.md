# Firmware ESP32 (satélite) — Miguel

Etapa atual: **Wi-Fi**.  
Depois: MQTT → gerar dados → criptografia → montar pacote → publicar.

## Arquivo

Só isto: `satelite/satelite.ino`

1. Abra no Arduino IDE (placa ESP32).
2. Troque `ssid` e `senha` no próprio arquivo.
3. Grave e abra o Serial em **115200**.
